# Arity

<img src="./images/logo.png" alt="" class="right" style="width: 164px; padding-left: 10px; padding-bottom: 10px" />

Arity is a language server, formatter, and linter for the R language. It is
built in Rust on a lossless, incremental parser, providing a fast, deterministic
development experience that integrates with popular code editors and IDEs.

## Quick Start

Install with Cargo:

```bash
cargo install arity
```

Format your first document:

```bash
arity format file.R
```

Run lint checks:

```bash
arity lint file.R
```

For full installation options (prebuilt binaries, package managers, and source
builds), see [Getting Started](getting-started.md).
