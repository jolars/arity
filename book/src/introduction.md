# Arity

Arity is a language server, formatter, and linter for the R language.

This book is a proof-of-concept for **living documentation**: the lint rule
reference under [Reference](reference/rules.md) is generated by running the real
linter on example snippets (`cargo run --example docgen`), so the documented
diagnostics and autofixes can never drift from the implementation.
