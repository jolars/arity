# Arity

## Quick Start

Install with Cargo:

```bash
cargo install arity
```

Format your first document:

```bash
arity format file.R
```

Run lint checks:

```bash
arity lint file.R
```

For full installation options (prebuilt binaries, package managers, and source
builds), see [Getting Started](getting-started.md).
